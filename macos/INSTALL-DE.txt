Gruetze RetroSaver für macOS

1. Gruetze RetroSaver.app auf den Ordner Applications ziehen.
2. Die App aus Programme öffnen und die gewünschten Einstellungen speichern.
3. „Install / update system screensaver“ anklicken und die macOS-Installation bestätigen.
4. In Systemeinstellungen > Bildschirmschoner Gruetze RetroSaver auswählen.
   Bei einer vorhandenen Installation kann der Name noch C64Screensaver lauten.

Die App enthält den echten System-Bildschirmschoner. Kein zweiter Download nötig.
App und Bildschirmschoner verwenden dieselbe Einstellungsdatei. Gespeicherte
Änderungen werden in einer laufenden Vorschau innerhalb etwa einer Sekunde geladen.
Bei Änderungen im nativen Optionsdialog lädt die Begleitapp beim Zurückwechseln nach.

Dieses Entwickler-Testpaket ist ad-hoc signiert, aber nicht notarisiert.
Für die öffentliche Verteilung muss es mit Developer ID signiert und notarisiert werden.
